# OLS (Open Local Server) v2.6.0

**Release date:** 2026-11-01 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Maintenance and UI release improving notifications, persistent UI caching, dashboard responsiveness, runtime version management, checksum verification, and port detection.

## Highlights
- **Persistent UI Caching**: Instantaneous 0ms page rendering across application restarts; optimistic live updates for sites, databases, and runtimes without manual page refresh.
- **Dashboard Layout & Controls**: Responsive container (up to 1680px content area), full-width Web server status strip, clean borderless action buttons, and isolated per-service pending states.
- **Unified Notification System**: Centralized toasts with semantic tokens, smart pause/resume on blur/hover, deduplication, live progress for background tasks and runtimes, and a persistent notification history dropdown.
- **State Banners & Clean Confirmations**: Persistent inline banners for active conditions (unapplied web server changes, port collisions); replaced noisy confirmation dialogs for reversible actions with instant Undo toasts.
- **Runtime Updates UI**: Clear "Up to date" and "Update available" status, bulk "Update all" action, and filter tabs (All, Updates available, Installed).
- **Major Upgrade Protection**: Semver major boundary detection with breaking change confirmation dialogs before installing major upgrades.
- **Prerelease Filtering**: Pre-release builds (alpha/beta/RC) are excluded from default updates; added channel toggle in the Manage panel. Node.js strictly targets LTS.
- **Dynamic Checksum Resolution**: Automatically verifies upstream SHA-256 sidecars when vendor archives are rebuilt in-place.
- **Process & Port Fixes**: Permitted deleting inactive runtime versions while a service runs; fixed Port Checker false positives showing PID 0 as "System Idle Process".

## Upgrading
Run `OLS-v2.6.0-setup.exe` to upgrade. Existing configuration, sites, databases, and certificates are preserved.

# OpenLocalServer v1.1.0

**Version:** 1.1.0 · **Date:** 2026-09-29 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only
**Previous:** [v1.0.0](./v1.0.0.md) — 76 commits, 204 files changed.

## Highlights

- **CPU caps** — Settings → Resources can cap a service's CPU (share of CPU or
  thread count) via vendored `cpulimit`. A cap that can't be applied is refused
  loudly, never silently uncapped.
- **`localhost/<prefix>` works** — Nginx/Apache/Caddy proxy to the site HTTPS
  vhost with SNI and `X-Forwarded-Prefix`. Add-site autofills the prefix from the
  project name.
- **One "Stop all"** — `CoreCommand::StopAll` (tunnels → workers → web stack →
  services → 10s reap) replaces the two divergent commands, used by tray,
  Dashboard and HTTP `operate`.

## Interface

- **Cleaner sidebar** — static groups, active item stays highlighted.
- **Number fields** — ports, worker counts, memory limits and IDE ports all use
  the in-app stepper instead of the browser arrows.
- **Wider layouts** — Dashboard and Web server pages breathe between `lg` and
  `xl` instead of crowding; Services card keeps its state, name and five actions
  at any width.
- **Clearer sites** — delete/apply confirms name what is deleted; a site shows
  its default server; the welcome site cannot be renamed or deleted.
- **New card** — excluded sites and project folders.
- **Per-service logs** — open a service on its own log, not the shared one.
- **Clearer errors** — failed downloads and quarantined files say what happened
  and what to do; runtime downloads can be paused and cancelled.
- New icons and brand marks, theme-aware logos.

## Other changes

- Multiple web servers with their own ports; configurable default TLD.
- SSH keys detected on project import.
- Robustness: helper replies time out, poisoned lock recovery, site-settings read
  deadline + Retry, backup accepts `-`/`.`/space in DB names.
- State stored in SQLite (`data/app.db`) with DB Browser integration.

## Security

Unchanged: SHA-256 verified downloads, CA key on-device, secrets in OS keyring,
tunnel first-exposure confirmation, self-pinned `cpulimit` hash documented in
`vendor/cpulimit/README.md`.

## Known limitations

- **Tunnel binaries are found, not installed** — see README → Sharing & Tunnels.
- **Traffic inspector covers normal requests only** — WebSocket upgrades and
  streamed/chunked responses bypass capture, replay and the webhook tester.
- Memory limits apply at next service start.
- Windows only.

## Install

`Open-Local-Server-1.1.0-setup.exe` from release assets; verify against
`Open-Local-Server-1.1.0-SHA256SUMS.txt`. In-place upgrade keeps projects, sites,
databases and settings.

# OLS (Open Local Server) v1.1.0

**Release date:** 2026-09-30 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Incremental release. Product as described in [`v1.0.0.md`](./v1.0.0.md) is unchanged.

## Added
- Bulk site management on the Sites page: select with checkboxes, then enable/disable, add auto domains, move to another web server, or delete.
- New commands `bulk_set_domains_enabled`, `bulk_set_domain_server`, `bulk_remove_domains`. One `CoreResponse::Bulk` result reports what changed and what was skipped, with a reason per skip.
- Pagination on the Sites list.

## Fixed
- Explorer right-click entries opened OLS instead of adding the folder (`ols.exe` and `OLS.exe` are the same file on Windows). The CLI is now `olsc.exe`, found by name and refused if it is the running app.
- `ols <command>` opened the app instead of running the command line. The app ships as `OLS.exe` and Windows does not
  tell two names apart by case, so `ols` is the app — and a shim beside it could not help, because within one folder cmd
  resolves by `PATHEXT` and `.EXE` comes before `.CMD`. The app now hands any argument that is not its own to
  `olsc.exe` and exits with the command's exit code, so `ols` works with the GUI closed and there is no second name
  to install.
- The shell menu card no longer reports "installed" while every entry points at the app; it checks the command it actually wrote.
- Explorer entries use the app's `icon.ico` instead of falling back to the console icon.
- Folders on network shares can be added from the right-click menu. Explorer passes `UNC\server\share` and the core produced that same unusable spelling; both are fixed, and a local folder named `UNC…` is left alone.
- The Setup window's "Read the docs" link opens externally via `open_url`.
- Legacy Start menu entries are cleaned up on upgrade.
- Daemon shutdown logs a service the OS refuses to stop, instead of dropping it.

## Upgrading
`OLS-1.1.0-setup.exe`, verify against `OLS-1.1.0-SHA256SUMS.txt`. In place from 1.0.0: no settings, sites, secrets, service or certificate move.

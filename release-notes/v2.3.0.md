# OLS (Open Local Server) v2.3.0

**Release date:** 2026-10-23 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release introducing Dynamic DNS integration, direct site broadcast controls, and multi-interface networking.

## Added
- **Site Broadcast Controls**: Live broadcast status, one-click public URL copying, and start/stop controls integrated into the Site Domains panel.
- **Dynamic DNS (DDNS)**: Multi-provider DNS synchronization for custom domains (with Cloudflare verified and tested), automated conflict resolution, and router troubleshooting.
- **MCP Server**: New `ols-mcp` crate exposes OLS as a stdio Model Context Protocol server — JSON-RPC 2.0 tools for domains, services, tunnels, databases, web config, and tasks, plus `ols_run_command` escape hatch.
- **User Manual page**: Settings → User Manual with two tabs — User Manual (built-in guide) and Release Notes.

## Changed & Improved
- **Multi-Interface Web Binding**: Web servers (Nginx, Apache, Caddy) bind to `0.0.0.0` to support LAN requests and router port forwarding.
- **Tunnel Constraints**: Enforced single-provider tunnel instance rules per site and automated duplicate pruning.
- **SemVer helper-service versioning**: Administrator helper version compared against app version before install; stale helpers refused.

## Fixed
- **Host Header Routing**: Forwarded public host headers now properly route to virtual hosts across all web servers without falling through to 404.
- **Domain Alias Confirmation**: Added safety confirmation dialog before deleting domain aliases.

## Upgrading
Download `OLS-v2.3.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

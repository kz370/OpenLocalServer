# OLS (Open Local Server) v2.2.0

**Release date:** 2026-10-19 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release introducing custom site logos and icons with local WebP photo conversion, an offline Font Awesome icon catalog with full color customization, seamless site settings integration, and smooth glitch-free updates.

## Added
- **Site Logo & Icon Support**: Every site can now have an assigned logo or icon displayed directly in the Sites table row (`[Checkbox] [SiteLogo] | [Hostname & Details]`). Clicking the logo or selecting "Site logo / icon…" from the row menu directly opens the site settings modal.
- **Custom Photo Upload with WebP Conversion**: Pick any local image (PNG, JPEG, WebP, SVG, etc.) from your computer. It is converted client-side to WebP (256x256) and saved in the project root directory as `ols_site_icon.webp`. Custom photos render as square (`size-8` / `size-7.5`), `rounded-md`, subtle `shadow-xs`, `border border-border/60`, and `object-cover` so non-square images fill cleanly without distortion or letterboxing.
- **Offline Font Awesome Icon Library**: Built-in offline collection of Font Awesome vector icons (Rocket, Server, Globe, Code, Database, WordPress, React, Laravel, Node.js, Python, Terminal, Docker, Cloud, Sparkles, and more).
- **Full Color Customization for Font Awesome Icons**:
  - Interactive HTML5 color swatch picker.
  - Text input supporting CSS color names (`crimson`, `coral`, `royalblue`), Hex values (`#00b4d8`, `#10b981`), and `rgba(...)` color specs.
  - 13 quick color preset chips (Cyan, Teal, Emerald, Sky, Blue, Indigo, Purple, Rose, Orange, Gold, Crimson, Coral, and Translucent Cyan).
  - Quick "Reset Color" button to return to theme defaults.
  - Stored cleanly as `name|color` in the domain configuration.
- **Crisp Cyan Wireframe Globe Fallback**: If no custom photo or icon is selected, sites display a colorful yet understated stroke-based cyan wireframe internet globe (Tabler world style, `#00b4d8`/`#06b6d4`, naked stroke with no background box or border).
- **Dedicated Site Settings Tab**: Site Settings now includes a dedicated "Site logo / icon" page (`ImageIcon`) featuring a live table-row preview with optimistic local updates.

## Fixed
- **Zero Layout-Shift Icon Selection**: Resolved a layout glitch where success banners dynamically mounted and unmounted above the tabs, causing the entire dialog to violently jump up and down. Replaced with an inline, fixed-space `Saved ✓` badge and optimistic local state updates.
- **Window Styling & Fullscreen Transitions**: Removed outer window borders in windowed mode for a sleek borderless look with clean rounded corners (`rounded-xl`). When maximized or in full screen, the window automatically transitions to `rounded-none`, eliminating transparent corner cutouts and edge outlines across monitor boundaries.
- **F5 Refresh & Route State Persistence**: Fixed page reloads (F5, Ctrl+R, webview reload) resetting the app back to the Dashboard main page. The active page route, WebServer subtab (`webServerTab`), and Logs source (`logSource`) are now synchronized via URL hash and `sessionStorage`, ensuring that refreshing with F5 stays on and reloads the current page.

## Upgrading
Download `OLS-v2.2.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

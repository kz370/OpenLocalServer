# OLS (Open Local Server) v2.2.0

**Release date:** 2026-10-19 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release introducing an in-app updater, custom site logos and icons with full color customization, borderless window styling, and active page persistence across reloads.

## Added
- **In-App Updater**: Check for updates, download verified releases, and install new versions directly from **Settings → Updates**.
- **Site Logos & Icons**: Assign custom logos or icons to each site, displayed directly in the Sites list. Click a logo or use the site actions menu to customize it.
- **Custom Image Upload**: Pick any local image (PNG, JPEG, WebP, SVG) as a site logo with automatic scaling and optimization.
- **Offline Font Awesome Icons**: Built-in collection of popular brand and tech icons with full color customization (color picker, quick presets, and custom hex or CSS color names).
- **Site Settings Integration**: Dedicated "Site logo / icon" tab in Site Settings with a real-time preview.
- **Page Refresh (F5) Support**: Refreshing the app preserves your current page and active tabs instead of resetting to the Dashboard.

## Changed & Improved
- **Window Styling**: Borderless window design with sleek rounded corners that seamlessly adapt when maximized or entering full screen.
- **Updates Interface**: Streamlined update status banners with clearer progress indicators and direct links to release notes.
- **Helper Service**: Companion `ols-helper` service can now be updated directly from the Settings page.

## Fixed
- **API Documentation Link**: Corrected the API documentation link in Settings → Local API.
- **Site Dialog Stability**: Eliminated layout shifts when saving site logo settings.

## Upgrading
Download `OLS-v2.2.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

# OLS (Open Local Server) v2.11.0

**Release date:** 2026-11-08 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release.

## Added
- **Docker page updates instantly:** when a container starts, stops or is recreated, the list refreshes within a second and linked sites move to the new port. It only listens while the Docker page is open.
- **Command line for Docker:** manage containers, images, volumes and Compose stacks with `olsc docker` (for example `olsc docker ps`, `olsc docker compose up compose.yaml`). Removing things stays in the app.
- **Warnings for Docker sites:** Diagnostics tells you when a site's container is stopped (with a **Start** button) or missing, and when Docker is off while sites depend on it. It asks Docker only if a site is linked to a container.
- **Site bundles keep Docker details:** exporting a site keeps its Docker link and, with Project files, its compose file. Passwords are never exported; the import dialog reminds you to recreate them.
- **Dockerize a project:** generate a Dockerfile, a compose file and a `.dockerignore` for a PHP, Node, Python, Go, Rust, Ruby, Java, .NET or static project. The project is copied into the image (no slow Windows folder mount); in Development mode `docker compose watch` keeps the container in sync with your edits, and Production mode builds a small multi-stage image that runs as a non-root user. OLS also detects the services your project uses (MariaDB, PostgreSQL, MongoDB, Redis, RabbitMQ, Meilisearch, Mailpit) and adds them as real, version-pinned images with generated passwords kept in the Windows credential store, health checks, and the connection settings your app needs. Laravel queue workers and the scheduler, Sidekiq and Celery run as extra processes from the same image. It picks the right package manager, framework, language version and system packages for your libraries. OLS shows what it detected and the files first, and never overwrites. Also in the right-click menu of Projects and Sites (hide it in Settings → Sidebar).

## Upgrading
Download `OLS-v2.11.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

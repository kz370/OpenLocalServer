# OLS (Open Local Server) v2.11.0

**Release date:** 2026-11-08 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release.

## Added
- **Docker page updates instantly:** when a container starts, stops or is recreated, the list refreshes within a second and linked sites move to the new port. It only listens while the Docker page is open.
- **Command line for Docker:** manage containers, images, volumes and Compose stacks with `olsc docker` (for example `olsc docker ps`, `olsc docker compose watch compose.yaml`, `olsc docker dockerize my-site --create`). Removing things stays in the app.
- **Warnings for Docker sites:** Diagnostics tells you when a site's container is stopped (with a **Start** button) or missing, and when Docker is off while sites depend on it. It asks Docker only if a site is linked to a container.
- **Site bundles keep Docker details:** exporting a site keeps its Docker link and, with Project files, its compose file. Passwords are never exported; the import dialog reminds you to recreate them.
- **Dockerize a project:** makes a Dockerfile, compose file and `.dockerignore` for PHP, Node, Python, Go, Rust, Ruby, Java, .NET or static projects. The project is copied into the image, `docker compose watch` keeps it in sync while you edit, and a Production mode builds a small non-root image. OLS also adds the services it detects (database, Redis, queue, mail, search) as pinned images with generated passwords. It shows everything first and never overwrites. Also in the right-click menu of Projects and Sites (hide it in Settings → Sidebar).

## Upgrading
Download `OLS-v2.11.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

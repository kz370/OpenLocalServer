# OLS (Open Local Server) v2.1.0

**Release date:** 2026-10-18 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release with clearer site status filtering, safe excluded-sites deletion, configurable ignored folders, subtle domain-less project icons, and a fix for Caddy admin-port conflicts.

## Added
- **Move to `excluded_sites` on deletion**: Deleting a site or project now moves its folder into an `excluded_sites` subfolder in the same directory (with automatic `-1`, `-2` suffix collision resolution) rather than permanently deleting it. Certificates are revoked and records are removed from the database.
- **Configurable ignored folders**: Users can configure which folder names the app ignores (defaulting to `excluded_sites`) via Settings → Ignored folders, with options to add, remove, and rename ignored folders (which automatically renames matching directories across project roots on disk). The app's project scanner and auto domain sync skip these folders so their contents are never scanned or registered.
- **Hide/Exclude renamed**: The existing skip-list deletion method that keeps project files untouched on disk is now clearly labelled **Hide/Exclude** in both the Sites table actions and in Settings.
- **Subtle icon for domain-less projects**: Projects with no domain yet display a subtle project folder icon instead of sharing the bright HTML5 logo.
- The Sites page now opens on **Enabled**. A **Disabled** tab sits next to it, followed by the available site-type tabs and **All** at the end. Status counts follow the search, and changing a site's enabled state moves it to the matching status tab immediately.
- Color-coded icons distinguish the **Enabled**, **Disabled**, and **All** tabs at a glance.

## Fixed
- Caddy uses a stable localhost admin port derived from its install path instead of the shared fixed port `127.0.0.1:20019`. Its generated config and reload/stop commands use the same address, so another Caddy instance holding the old shared port no longer prevents Caddy from starting.

## Upgrading
Download `OLS-v2.1.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

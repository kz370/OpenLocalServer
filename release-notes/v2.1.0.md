# OLS (Open Local Server) v2.1.0

**Release date:** 2026-10-18 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release with clearer site status filtering and a fix for Caddy admin-port conflicts.

## Added
- The Sites page now opens on **Enabled**. A **Disabled** tab sits next to it, followed by the available site-type tabs and **All** at the end. Status counts follow the search, and changing a site's enabled state moves it to the matching status tab immediately.
- Color-coded icons distinguish the **Enabled**, **Disabled**, and **All** tabs at a glance.

## Fixed
- Caddy uses a stable localhost admin port derived from its install path instead of the shared fixed port `127.0.0.1:20019`. Its generated config and reload/stop commands use the same address, so another Caddy instance holding the old shared port no longer prevents Caddy from starting.

## Upgrading
Download `OLS-v2.1.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

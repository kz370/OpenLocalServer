# OLS (Open Local Server) v2.7.0

**Release date:** 2026-11-02 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature and management release introducing the dedicated Projects Management page, responsive project type filter bar, project metadata and framework presets, multi-editor configuration with broad IDE auto-detection, the system tray Projects submenu, Model Context Protocol (MCP) AI tooling, on-accent contrast accessibility, and streamlined cross-page navigation.

## Highlights
- **Dedicated Projects Management Page**: Manage standalone project directories with or without local virtual host domains from a dedicated UI view (`Projects`). Features real-time search across names, filesystem paths, and connected domains, plus pagination with configurable page sizes.
- **Folder Status & Drive Filtering**: Features an **All** vs **Folder not found** tab view to instantly isolate projects whose local folders or external drives are disconnected or missing, with quick locate and copy-path actions.
- **Responsive Single-Line Project Type Filter Bar**: Single-line layout using `ResizeObserver` and offscreen button measurement. Automatically filters down to types with $\ge 1$ project (excluding empty presets and unused custom types), keeps "All" first, and pins "Manage types" to the far right.
- **Dynamic Overflow Popover & Active Tab Swapping**: Chips exceeding the available bar width collapse into a "+N more ▾" popover with integrated instant search and total project counts. Selecting a type from the popover dynamically swaps it into the visible row, combined with instant search (`AND` logic, counts staying totals).
- **Drag-to-Reorder & Pinning in Manage Types**: HTML5 drag-and-drop reordering for custom type tab sequences in `ManageProjectTypesDialog`, inline "Pin to filter bar" toggles to pin preferred types ahead of higher-count chips, and inline renaming preserving position, pin status, and active preferences.
- **Project Actions & Right-Click Context Menu**: Right-clicking any project row (or clicking the Actions trigger) opens a cursor-anchored context menu with active row highlighting:
  - **Create site from project**: 1-click local site creation for projects without a linked local virtual host.
  - **Open project directory**: Instantly launches the project folder in Windows Explorer.
  - **Open with editor**: Submenu listing all installed and visible code editors.
  - **Open terminal**: Spawns an external Windows Terminal (`wt.exe`) or PowerShell session rooted in the project directory.
  - **Project settings**: Modify display name, project type, and custom WebP icons.
  - **Hide from list**: Safely hides registered projects from the main list.
- **Project Removal Protection & Safe Deletion**: Standalone projects connected to active virtual host sites are protected from accidental removal or deletion with clear diagnostic error feedback (`CoreError::failed_fix`). Scanned projects remain removable and trackable in the deletion skip history (`PROJECT_SKIP`). Added Windows 8.3 short name (e.g. `RUNNER~1` on CI runners) canonicalization in path matching (`same_path`).
- **Project Metadata & Framework Presets**: Edit project metadata via `ProjectSettingsDialog`. Includes a bundled preset catalog (`catalog/project-types.yaml`) covering 17 popular frameworks and languages (Laravel, Symfony, WordPress, PHP, Python, Django, Flask, FastAPI, Node, Next.js, React, Vue, Go, .NET, Java, Static HTML, Other) with custom type support.
- **Tauri Preset & Project Auto-Detection**: Native auto-detection for Tauri applications (`src-tauri/tauri.conf.json`, `Cargo.toml`, etc.) resolving to `custom:Tauri` with official Tauri branding.
- **Folder Drag-and-Drop Dropzone**: Dropping any folder from Windows Explorer onto the Projects page triggers an animated full-screen dropzone overlay and queues the Add Project modal, pre-populating folder details and auto-detected framework presets.
- **Windows Explorer Context Menu Integration**: Right-clicking a directory in Windows Explorer shows **"Add folder to OLS projects"**, instantly launching or focusing OLS and opening the project configuration dialog with pre-filled path inspection.
- **Duplicate Path Validation & Diagnostic Feedback**: Enforces path uniqueness (`same_path` canonicalization across drive casing, trailing slashes, Windows 8.3 short names, and Windows extended paths). Prevents duplicate registrations with structured problem-cause-fix diagnostics while supporting identical folder names at different filesystem locations.
- **Custom Project Types Management (CRUD)**: Manage, create, rename, and remove custom project types (`ManageProjectTypesDialog`). Renaming a custom type updates all associated projects automatically; deleting a custom type safely resets those projects to "Auto".
- **Multi-Editor Configuration & Broad Auto-Detection**: Auto-detects installed development IDEs and editors: VS Code, Cursor, Windsurf, Trae, Zed, VSCodium, Sublime Text, Notepad++, and JetBrains IDEs (PhpStorm, WebStorm, PyCharm, IntelliJ IDEA, GoLand, RustRover, Rider via JetBrains Toolbox and standard program roots). Windows Notepad is excluded from the auto-detected code editor list.
- **Custom Code Editors & Visibility Toggles**: Add any custom code editor by executable path (`AddEditor`, `UpdateEditor`, `RemoveEditor`). Hide or show any auto-detected or custom editor from menus and pickers with an Eye/EyeOff toggle in `Settings > General > Code editor` (`CONFIGURED EDITORS`).
- **On-Accent Contrast & Theme Icon Rendering**: Added `--on-accent` CSS variable dynamically derived from accent color luminance (OKLCH relative color syntax with JS relative luminance fallback in `applyThemeToDom`). Ensures high contrast text, icons, and count badges on active accent chips and primary buttons. Converted generic and brand icons (`FolderCode`, brands) to `currentColor`. Added dual WCAG contrast warnings in the custom theme editor evaluating accent vs background and accent vs on-accent.
- **Model Context Protocol (MCP) Project & Editor Tools**: Added 9 new tools to the built-in MCP server (`ols-mcp`) for AI coding assistants: `ols_list_projects`, `ols_add_project`, `ols_update_project`, `ols_inspect_project_folder`, `ols_list_project_types`, `ols_add_custom_project_type`, `ols_rename_custom_project_type`, `ols_remove_custom_project_type`, and `ols_list_editors`.
- **System Tray Projects Submenu**: The right-click system tray menu now features a categorized **Projects** submenu directly below Sites. Each registered project provides two dedicated actions:
  - **Open directory**: Opens the project directory in Windows Explorer (`open_path`).
  - **Open with**: Submenu listing all installed, non-hidden code editors (`open_with`).
  - **Open projects**: Bottom navigation item switching the main window directly to the Projects page (`navigate(app, "projects")`).
  - **Dynamic Tray Synchronization**: Tray menus dynamically rebuild in real-time when projects or editors are added, renamed, or modified.
- **Deep-Linked Settings Navigation**: Seamless cross-page navigation (`openSettingsSection`) allows 1-click jumps directly from menus (e.g. "Edit editors...") straight to the target Settings section.

## Upgrading
Run `OLS-2.7.0-setup.exe` to upgrade. Existing configuration, sites, databases, certificates, and settings are preserved.

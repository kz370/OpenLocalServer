# OLS (Open Local Server) v2.0.1

**Release date:** 2026-10-01 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release. Everything in [`v1.2.0.md`](./v1.2.0.md) still works the same way.

## Added
- **Site bundles** — export one or many sites to a single `*.olsbundle.zip` from a site's `⋯` menu or the
  bulk bar, and import it back. Four independent switches (settings, `.env` files, databases, project files);
  settings and `.env` on by default. An optional password seals the `.env` files and the database dumps
  (Argon2id → ChaCha20-Poly1305), never the code or the manifest.
- **Background tasks** — an export or import answers with a task id instead of blocking. The Processes page
  gains a Background tasks tab with per-step progress, cancel, and a report of what worked and what did not.
- **Automatic backups** (`auto_backup` settings) — project snapshots and database dumps on a schedule, with
  a keep count. Scope is the whole app or a chosen set of sites, and under the chosen-sites scope each site
  can set its own period, keep count and what gets copied.
- **Desktop notifications** — app-owned Windows toasts for crashed processes, finished installs, finished
  Quick Apps, completed auto-fixes and hidden launches. Toggle in Settings → Startup.
- Service marks are now one shared component, so a service looks the same on the Dashboard, the Services page
  and the Databases banner.

## Changed
- The project page holding the snapshots is called **Backups**, not Snapshots: a database dump belongs next to
  the snapshot that records its database.
- A site's on/off backup switch is inert under the app-wide plan (shown greyed with the way out) instead of
  reporting success and changing nothing.

## Fixed
- Backup and Restore spinners are per row. Backing up one database no longer spins every sibling's button.
- Alerts wear the app's identity and icon, not PowerShell's.

## Upgrading
`OLS-v2.0.0-setup.exe`, verify against `OLS-v2.0.0-SHA256SUMS.txt`. In place from 1.2.0: no settings, sites,
secrets, service or certificate move. New settings keys (`auto_backup`, `auto_backup_state`,
`notifications`) default to off — automatic backups and notifications are opt-in.

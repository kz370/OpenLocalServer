# OLS (Open Local Server) v2.10.0

**Release date:** 2026-11-07 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Adds a Docker page for containers and Compose stacks, and makes the Projects and Sites lists easier to manage and faster.

## Added
- **Docker page** (Sites → Docker): search and group containers by Compose project, start, stop, restart or pause them, open ports, read logs, open a shell, and edit settings and environment variables. Docker stays optional; OLS never installs it.
- **Images and Volumes:** sizes, pull, run and remove. **Reclaim space** shows what a cleanup removes before it does anything.
- **Compose:** stacks with Up, Stop, Down, Pull and Build, a built-in editor with **Check**, and a builder that picks free ports and keeps passwords in the Windows credential store. Save your own services as presets.
- **Connect to OLS and Create site:** containers can reach your OLS sites and services by name, and any container can get a local HTTPS site.
- **AI assistant tools** for Docker in the OLS MCP server.
- **Settings → Sidebar:** hide pages you don't use.
- **Projects:** select several projects, then Create sites, Hide or Remove from list in one step.
- **Projects and Sites:** group rows by root folder, or sort by it.

## Improved
- Docker does nothing until you open its page, and its lists load from a cache.
- Sites and Projects load faster and show a spinner while loading. Remove from list is instant and also works when the project folder is gone.

## Security
- **DDNS credentials** are kept in the Windows credential store, not in site settings. Existing ones move on the first start. Snapshots and site bundles no longer include them, so enter them again after importing a site on another computer.
- **PHP extensions (PECL)** install only when OLS knows the file's SHA-256: apcu, redis, igbinary, imagick, mongodb, xdebug, pcov and yaml for PHP 8.1–8.5.
- **Compose editor** saves only stacks OLS knows. Site bundle imports can't write outside their folders.
- **AI assistant (MCP)** can no longer read stored passwords, confirm a tunnel, or overwrite a compose file.
- Updated TLS and zip libraries.

## Fixed
- Compose **Check** no longer reports a port conflict for TCP + UDP or separate addresses.
- Turning Docker sites on or off handles every container, even when one fails.
- Starting a tunnel twice no longer runs two copies.
- Text like `<name>` in release notes and the manual is visible again.
- Processes → Usage by site: the table header matches the card.
- Right-click no longer opens the browser's menu (text fields keep Cut, Copy and Paste).

## Coming next
- **Command line for Docker:** manage containers, images, volumes and Compose stacks with `olsc docker`.
- **Warnings for Docker sites:** Diagnostics tells you when a site's container is stopped or missing.
- **Site bundles keep Docker details:** exports keep a site's Docker link and compose file, but never its passwords.
- **Dockerize a project:** generate a Dockerfile and compose file for a project in one click.

## Upgrading
Download `OLS-v2.10.0-setup.exe` and run the installer. Your settings, sites, databases, services and certificates are kept.

# OLS (Open Local Server) v2.10.0

**Release date:** in development · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release that adds a Docker page: see and control your Docker containers, and turn a container into a site with its own `.test` domain and HTTPS.

## Added
- **Docker page:** a new **Docker** item under **Sites** in the sidebar. See whether Docker is running, and start Docker Desktop with one click.
- **Your containers in one list:** grouped by Compose project, with filters for running containers, containers linked to sites, and containers created by OLS.
- **Control containers:** start, stop, restart, pause and resume a container. Click a port to open it in your browser.
- **AI assistant tools:** the OLS MCP server can now check Docker, list containers and start, stop or restart them. It can also bring back a site you hid with `.ols_ignore_site`.

## Changed & Improved
- Docker is optional and never slows OLS down: nothing Docker-related runs when OLS starts, and the Docker page only talks to Docker while you have it open.

## Coming before 2.10.0 ships
- Turn a container into a site with its own `.test` domain and HTTPS.
- Ready-made Docker apps (templates), container logs and a shell inside a container.

## Upgrading
Download `OLS-v2.10.0-setup.exe` and run the installer. Your settings, sites, databases, services and certificates are kept. Docker is optional: OLS does not install it, and nothing changes if you don't use it.

# OLS (Open Local Server) v2.8.0

**Release date:** 2026-11-03 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release with easier project selection, faster Quick App search, and safer database maintenance.

## Added
- Searchable Quick App selection and an option to attach an existing unconnected project when adding a site.
- Read-only SQLite views and indexes for easier data queries.
- Restore missing WordPress core files from Sites or Project Repair, with checksum validation and offline cache support.

## Changed & Improved
- Projects stay standalone unless site creation is requested, and can be connected later from site selection.
- Versioned database migrations back up the database before changes; operation history now has retention and repeated-failure cleanup.
- Sites now offer Hide, Remove from list, and Safe delete with Undo. Open with editor uses configured editors throughout the app; existing editor settings migrate once.
- Background Tasks keeps recent site-operation history across restarts and groups repeated operations.
- Site Health Check shows each DNS, TCP, TLS, certificate, trust, and HTTP stage as it completes.

## Upgrading
Download `OLS-v2.8.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

# OLS (Open Local Server) v2.9.0

**Release date:** 2026-11-05 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release with easier database import, an Explorer menu for projects, a way to hide only a site, and steadier pages.

## Added
- **Import databases from several places at once:** your installed OLS MariaDB versions, other MySQL/MariaDB installs on your PC, or any data folder. They import in the order you choose.
- **Choose what happens with duplicate databases:** skip, replace (backed up first), or import under a new name. An import that was interrupted is recovered next time you start the app.
- **Explorer menu:** right-click a folder and choose Show more options → Open Local Server to add, set up, or ignore a project. Turn it on in Settings.
- **Hide only a site:** an `.ols_ignore_site` file hides a project's site but keeps the project. Use **Unignore site** on Projects to bring it back.
- **Many more icons for sites and projects:** over 400 icons in clear categories, including popular CMS, shop, hosting and payment brands, plus categories like Food & Drink, Travel, Health, Education and Games.

## Changed & Improved
- A simpler Import databases window, in three clear steps.
- Light and dark mode each keep their own background.
- Editor settings have their own section in Settings.
- Sites, Projects, Runtimes and Databases pages no longer jump around while loading.
- Background Tasks has pages and asks before clearing history.
- Projects update right away when something changes.
- Upgrading no longer asks you to reinstall the administrator helper unless it changed.
- Icon pickers are faster and easier to browse by category.
- Automatic fixes happen right away when something changes, and Diagnose on the Repair page fixes what it safely can.

## Fixed
- Add Site picks the right folder for a project's site.
- The tray shows the correct number of running services.
- Project commands now use the right PHP version.
- A site's Repair page shows only that site's problems.
- Saving settings and sites is faster.
- Long paths in tooltips no longer overflow the window.
- Database import counts stay correct when you change selections quickly.
- The Explorer menu installs and shows its actions reliably.

## Upgrading
Download `OLS-v2.9.0-setup.exe` and run the installer. Your settings, sites, databases, services and certificates are kept. If you installed the Explorer menu in an earlier build, open Settings and choose **Repair** to update it.

# OLS (Open Local Server) v2.9.0

**Release date:** 2026-11-05 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release with multi-source database import, an Explorer submenu for project actions, site-only ignore markers, and steadier page layouts.

## Added
- **Import databases from several sources at once:** pick installed OLS MariaDB versions, auto-detected MySQL/MariaDB installs, or any data folder via Browse. Sources import in the order you choose; every selected source must be scanned before Import is enabled.
- **Database conflict handling:** choose Skip existing (default), Replace existing (a SQL safety backup is taken first and restored if the import fails), or Rename incoming (picks a unique name). Interrupted imports are recovered or rolled back on next start.
- **Explorer "Open Local Server" submenu:** right-click a folder and choose Show more options to reach Add folder, Set up, Ignore project, and Ignore site. Turn it on from Settings with Add to Explorer; Repair and Remove are there too.
- **`.ols_ignore_site` marker:** hides and deactivates a project's site while keeping the project visible. Projects shows **Unignore site** for those projects. `.ols_ignore_me` still hides both.

## Changed & Improved
- Import databases dialog: three numbered steps, collapsible source rows with inline password, Scan, and progress, filterable database tiles, and one footer status line. The current MariaDB data folder is no longer offered as a source.
- App background is stored per light/dark mode. A gradient chosen in one mode is adapted for the other until you set it, so dark gradients no longer sit behind light cards.
- Editor settings moved out of General into their own Settings sidebar section.
- Sites: web-server status and Start/Stop sit in a fixed chip beside the heading; toolbar buttons are grouped.
- Background Tasks is a paginated table (10/25/50/100 rows) and asks before removing finished tasks or clearing history.
- Steadier layouts on Sites, Projects, Runtimes, and Databases: fixed row heights, loading skeletons, and error messages that overlay instead of pushing content.
- Sites and Projects show clearer Auto-discovered and Added manually labels.
- Projects refresh on change events instead of polling every 3 seconds; adding or removing an ignore marker updates the lists right away.
- Choosing a new default MariaDB points to Databases → Import databases; removing an old MariaDB warns that its files are needed to import from it.
- Upgrading the app no longer asks to reinstall the administrator helper unless the helper itself changed.

## Fixed
- Add Site now uses a project's detected document root instead of its top folder.
- Project Settings stays on the Icon & Logo tab when the project-type list refreshes.
- Tray tooltip no longer shows stale running-service counts.
- Long paths in tooltips wrap instead of overflowing the window.
- Import database counts no longer drop to zero after quick checkbox changes.
- Explorer menu: all four actions now appear as a real submenu with icons, ignore actions no longer flash a console, and install refuses a mismatched `olsc` version instead of failing silently.

## Upgrading
Download `OLS-v2.9.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates. If you installed the Explorer menu in an earlier build, open Settings and choose **Repair** to replace the old entries.

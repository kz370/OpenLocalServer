# OLS (Open Local Server) v2.0.2

**Release date:** 2026-10-10 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Patch release addressing Apache HTTP Server installation issues.

## Fixed
- **Apache installation failures**:
  - Resolved checksum mismatch on Apache 2.4.68 by updating the built-in catalog to Apache 2.4.69 with its verified SHA-256 checksum.
  - Fixed an issue where resolving Apache 2.4.69 truncated the archive download URL, causing a path error (`os error 3`) during extraction.

## Upgrading
Download `OLS-v2.0.2-setup.exe` and run the installer. In-place upgrade from earlier versions preserves all existing configuration, sites, and databases.

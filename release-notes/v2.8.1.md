# OLS (Open Local Server) v2.8.1

**Release date:** 2026-11-04 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature and UI release.

## Changed & Improved
- UI refinements: clearer Sites controls, stable layouts on Sites, Projects, and Runtimes, and a paginated Background Tasks table.
- Moved editor settings out of General into their own Settings sidebar section.

## Upgrading
Download `OLS-v2.8.1-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

# OLS (Open Local Server) v2.4.0

**Release date:** 2026-10-24 · **Platform:** Windows 10/11 (64-bit) · **License:** GPL-3.0-only

Feature release introducing Python runtime and virtualenv management, the Model Context Protocol (MCP) server, refreshed circular branding, and built-in manual pages.

## Added
- **Python Runtime & Virtualenv Support**: First-class support for Python runtimes (3.7–3.15) alongside PHP and Node.js. Automatically discovers local virtualenvs (`.venv`, `venv`, etc.) and system installations on PATH, wiring runtime execution and environment variables dynamically for supervised web apps.
- **Model Context Protocol (MCP) Server**: Bundled `ols-mcp` companion server implementing stdio JSON-RPC 2.0 with bearer-token authentication. Enables AI assistants and IDEs to manage sites, runtimes, background services, databases, and tasks.
- **Smart Folder Inspection**: Automatic project inspection discovering entry files, package managers, virtualenvs, suggested start commands, and port allocations.
- **User Manual Page**: Added built-in User Manual and Release Notes viewer under `Settings → User Manual`.

## Changed & Improved
- **Circular Application Branding**: Refreshed all application icons (system tray, sidebar, titlebar, taskbar, website, and home site) with circular antialiased marks.
- **Dark Executable & Setup Icons**: The main application executable (`OLS.exe`) and installer setup (`OLS-Setup.exe`) now default to the dark circular mark across all icon sizes (16px to 256px).
- **Runtime Management**: Deduplicated installed runtimes display and filtered unavailable online upstream builds.

## Fixed
- **MariaDB Local Root Authentication**: Automated bootstrapping for MariaDB root permissions to ensure seamless passwordless local TCP connections.
- **Isolated Node & Python Start Commands**: Separated start command lines in site settings so Node and Python processes never cross-pollinate.

## Upgrading
Download `OLS-v2.4.0-setup.exe` and run the installer. In-place upgrade from earlier versions preserves existing configuration, sites, databases, secrets, services, and certificates.

--- FRONTEND pages ---
DashboardPage | Overview with health filter + stop-all. Web server + Services cards render from one `get_dashboard` poll; a failed poll surfaces its Diagnostic instead of leaving them on "Loading…". Services widget lists all 9 built-ins in fixed order (mailpit, mariadb, postgres, mongodb, redis, memcached, nginx, apache, caddy) and collapses the port column and state pill to a titled dot below the sm breakpoint so the service name never squeezes out in a narrow window. Row controls (start/stop/restart/reload/logs) are colour-coded per action — start emerald, stop destructive red, restart amber, reload sky, logs violet — held at reduced opacity so the strip stays readable; an action the row cannot take right now (not installed, already in that state, no log source, another command running) renders flat grey with `disabled:opacity-100` and no hover response, so "unavailable" never looks like a live control. Card order flips by width: the two-column layout puts Overview in the left column and Web server stacked over Services in the right one, while the windowed/single-column layout leads with the Web server card, then Overview, then Services (`contents lg:flex` on the right-hand wrapper plus `order-1/2/3 lg:order-none`), so the narrow window answers "is the web server up?" before the load graphs.
SitesPage | Domains+projects merged table, group/search/duplicate. New Git clone / import / QuickApp defaults to <install>\sites (quickapps.projects_dir override); each dialog shows resolved path, folder name + location editable; Git clone supports SSH auth with ~/.ssh key detection dropdown, refresh button, and file-picker fallback.
QuickAppsPage/Wizard | Recipe CRUD + compact responsive recipe grid (4-col xl, 3-col lg, compact cards) + 3-phase plan/run wizard.
CommandsPage | Discovered+custom commands runner with output ring.
WebServerPage | Server/ports/certs tabs + settings save-apply.
ConfigPage | Config files + history diff/restore + ownership.
TunnelsPage | Tunnel CRUD + inspector + webhook tester.
DatabasesPage | Per-engine DB/users/backups + external tools (Redis one-click via Tiny RDM).
ServicesPage | Mail/DB services + CustomServices child.
RuntimesPage | Side-by-side versions + PHP dialogs; vendor feed refresh for the ONLINE_CATALOGS ids (TechIcon per runtime: mailpit envelope, git brand, others simple-icons); Pause/Resume/Stop on every download in flight.
ProfilesPage | Env template CRUD + yaml editor.
PluginsPage | Plugins + signed catalog sources.
LogsPage | Unified logs with severity regex + AI ask (error/warn picker, timestamp-blind dedupe with ×count, overlong pick spills to .log file via read_excerpt).
ProcessesPage | Raw process manager + system stats.
SettingsPage | General/sites/startup/AI/API/resources/backups/about.
